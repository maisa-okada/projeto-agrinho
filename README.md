# 🌱 Raízes do Amanhã

Projeto desenvolvido para o Concurso Agrinho.

## Sobre

Raízes do Amanhã é uma experiência interativa que apresenta a importância da união entre tecnologia, produção agrícola e sustentabilidade.

Através da personagem Lia, uma jovem apaixonada pela natureza e pela inovação, o visitante descobre como as novas tecnologias ajudam a preservar recursos naturais e garantir um futuro mais sustentável.

## Objetivos

* Conscientizar sobre sustentabilidade.
* Demonstrar a importância da agricultura moderna.
* Mostrar o uso da tecnologia no campo.
* Incentivar o cuidado com o meio ambiente.
